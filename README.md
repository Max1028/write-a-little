# 慢慢寫 · Write a Little

英文作文練習網頁：8篇完整兩段範例、句型拆解、總—分—總提示、限時模考、局部文法修改對照與本機紀錄。

## 使用

GitHub Pages啟用後，從儲存庫右側的網站連結開啟。`index.html`為可獨立運作的完整網頁；不需安裝套件。作文存在各自瀏覽器，請定期匯出備份。

## 限時練習

可選15、20、25或30分鐘，涵蓋審題、提綱、寫作與檢查。模考不暫停，重新整理不會重設期限；交卷後鎖定限時稿，考後修改另行保留。這是練習配置，並非官方作文獨立時限。

## Gemini批改後端

`worker.js`為可部署至Cloudflare Workers的完整後端與網頁，設定見`wrangler.jsonc`。GitHub Pages只能執行靜態網頁，不能保管Gemini金鑰或執行後端；因此目前Pages提供基本練習，AI功能仍待後端部署與金鑰設定。

部署後只在後端的秘密環境變數設定`GEMINI_API_KEY`與`APP_ACCESS_CODE`，並設定`ALLOWED_ORIGINS=https://max1028.github.io`與可用模型`GEMINI_MODEL`。在網頁右上設定填入後端HTTPS網址及家庭存取碼即可。不要把實際金鑰或存取碼寫入任何檔案或提交至GitHub。

使用AI時會先取得同意，再傳送題目、提綱、作文與前稿。AI回饋包含原句、建議修改與中文說明，估分不是正式閱卷。免費額度與資料政策依Google當期條款。
